1. 평소처럼 읽어보기

먼저 평소처럼 이야기를 읽어봅시다. 어떤 일이 있었는지 편하게 살펴보세요.

루미: “처음에는 그냥 읽어도 괜찮아. 먼저 무슨 일이 있었는지 알아보자!”

사라진 발표 카드

아침 독서 시간이 끝나자, 지우는 책상 속을 조용히 뒤지기 시작했습니다. 오늘은 모둠 발표를 하는 날이었고, 지우는 어젯밤 늦게까지 발표 카드를 정리해 두었습니다. 그런데 아무리 찾아도 카드가 보이지 않았습니다.

옆자리에 앉은 민서는 지우의 얼굴이 점점 어두워지는 것을 보았습니다. 잠시 뒤, 민서는 자기 공책을 찢어 빈 종이를 건네며 말했습니다. “지금부터라도 같이 다시 써 보자.” 지우는 고개를 끄덕였지만, 눈에는 금방이라도 눈물이 고일 것 같았습니다.

2. 질문과 함께 읽기

이번에는 이야기 속 장면을 보며 질문을 열어봅시다.
질문에 답하며 읽다 보면 그냥 지나쳤던 부분을 다시 생각할 수 있습니다.

루미: “질문을 떠올리면 이야기가 조금 다르게 보이기 시작해!”

3. 내가 궁금한 질문 만들기

이야기를 읽으며 새롭게 궁금해진 점을 질문으로 만들어봅시다.

루미: “처음부터 완벽하지 않아도 괜찮아. 궁금한 마음을 질문으로 바꿔보자!”

질문 만들기 도움

아래 도움 버튼을 누르면 질문을 시작하는 말을 가져올 수 있습니다. 문장을 이어서 나만의 질문을 완성해 보세요.

4. 생각 나누기

내가 만든 질문과 친구들이 만든 질문을 함께 살펴보고, 친구들의 답을 참고해 내 생각을 이어 적어봅시다.

루미: “같은 글을 읽어도 질문과 답은 서로 다를 수 있어. 친구들의 생각을 보며 내 생각도 넓혀보자!”

친구 질문과 답
하윤의 질문 선택됨

지우는 왜 혼자 카드부터 찾으려고 했을까요?

준서 처음에는 너무 당황해서 친구에게 바로 말하지 못했을 것 같아요.

소민 스스로 해결해 보려고 했지만 점점 불안해졌을 것 같아요.

준서의 질문 질문

민서는 왜 지우를 바로 도와주려고 했을까요?

하윤 지우가 속상해하는 모습을 보고 그냥 지나칠 수 없었을 것 같아요.

소민 친구가 어려울 때 함께 해결하고 싶었기 때문이라고 생각해요.

소민의 질문 질문

발표 카드가 없어졌을 때 지우의 마음은 어땠을까요?

하윤 열심히 준비했는데 사라져서 속상하고 막막했을 것 같아요.

준서 발표를 못 하게 될까 봐 걱정했을 것 같아요.

루미: “카드를 알맞은 곳에 나누어 보면 질문하며 읽기의 힘을 더 잘 알 수 있어!”
